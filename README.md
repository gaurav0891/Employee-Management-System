# Employee Management System (Java)

## Description
A file-based Employee Management System built using Core Java.
No database is used; data is stored in files.

## Features
- Add Employee
- View Employees
- Persistent Storage using File Handling

## Technologies
- Java
- OOP
- File I/O
- Collections

## How to Run
1. Clone the repo
2. Compile the project
3. Run Main.java
